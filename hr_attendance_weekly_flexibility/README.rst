This module allows to set work schedules to only account for a weekly
target of work.

Employees can file as little or as many attendances in a given week. Any
undertime and overtime is counted from or away from the weekly target of
work.

Known issues / Roadmap
======================

- As over/undertime is only attached to attendance records, any due
  worktime is only accounted for on further attendances.
